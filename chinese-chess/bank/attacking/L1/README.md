# 策略基因 - L1 级别

## 目录说明
此目录用于存储 策略基因 的 L1 级别根基因数据。

## 级别定义
- L1 基础: 基本的单一概念和简单应用
- L2 组合: 多个概念的组合和中等复杂度
- L3 复杂: 高级策略和复杂的多步骤思维

## 文件命名规范
现有棋局使用 `at_中文棋局名_L1-001` 格式（以棋局编号中的实际等级为准）。
名称或分类尚待核实的棋局标记为“待定”，原编号保留在 `originalId` 字段；重名棋局使用不同序号。
以下时间戳格式是原有根基因文件说明，不是本次棋局编号规范。

基因文件按照以下格式命名：
`[基因名称]_[时间戳].json`

例如：
- 车马配合_L1_001_20250904_143022.json
- 兵卒推进_L2_002_20250904_143045.json

## 数据结构
每个基因文件包含：
- gene_info: 基因基本信息
- generation_params: 生成参数
- generated_data: 生成的数据内容  
- metadata: 元数据信息
