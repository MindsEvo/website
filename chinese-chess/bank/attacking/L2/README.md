# 策略基因 - L2 级别

## 目录说明
此目录用于存储 策略基因 的 L2 级别根基因数据。

## 级别定义
- L1 基础: 基本的单一概念和简单应用
- L2 组合: 多个概念的组合和中等复杂度
- L3 复杂: 高级策略和复杂的多步骤思维

## 文件命名规范
基因文件按照以下格式命名：
`[基因名称]_[时间戳].json`

例如：
- 车马配合_L1_001_20250904_143022.json
- 兵卒推进_L2_002_20250904_143045.json

## 数据结构
每个基因文件包含：
- gene_info: 基因基本信息
- generation_params: 生成参数
- generated_data: 生成的数据内容  
- metadata: 元数据信息
