# 残局基因 - L1 级别

## 目录说明
此目录用于存储 残局基因 的 L1 级别根基因数据。

## 级别定义
第一部分：单子对光将 - 认识你的武器
目标：建立最基础的子力控制直觉，了解每个棋子的“绝对威力”。
第二部分：打破防守 - 对阵士象
目标：学习如何破解对方最基本的防御阵型，训练计算的精确性。
第三部分：子力协同 - 1+1>2
目标：理解子力配合的基本原理，体验组合的威力。
第四部分：巧胜与困毙 - 思维的升华
目标：训练观察力，发现局面的细微弱点，体验高级的“控制”艺术。

## 文件命名规范
基因文件按照以下格式命名：
`[基因名称]_[时间戳].json`

例如：
- 车马配合_L1_001_20250904_143022.json
- 兵卒推进_L2_002_20250904_143045.json

## 数据结构
每个基因文件包含：
- gene_info: 基因基本信息
- generation_params: 生成参数
- generated_data: 生成的数据内容  
- metadata: 元数据信息
