## 1. 定位

Pattern Hunter 是小精灵系列（MindSeeds）的核心模块之一。它不是学校「找规律」练习的游戏化版本，
而是从儿童游戏、经典智力活动和日常经验里提取与**模式识别**有关的基础思维活动。

关注的不是孩子「学会了多少种规律」，而是：**孩子是否越来越善于从复杂信息中发现结构与关系。**
基本原则：规律不是被讲出来的，而是被发现出来的。

与 Learning「规律」的区别：Learning 从知识和任务进入（理解 → 判断 → 使用）；Pattern Hunter 从游戏行为进入
（观察 → 尝试 → 发现 → 调整 → 再尝试）。两者允许重合，同一个 RootGene 可以同时存在于两个体系；底层思维相同，表层体验不同。

## 2. 核心认知链

| 级 | 名称 | 含义 |
|---|---|---|
| A | Observation 观察 | 发现对象与属性 |
| B | Comparison 比较 | 相同/不同、多/少、大/小、前/后 |
| C | Change Detection 变化检测 | 什么变了：属性、位置、数量、顺序、状态 |
| D | Relationship Discovery 关系发现 | 对象之间、前后之间如何对应 |
| E | Pattern Extraction 模式提取 | 从多个观察里抽出共同结构（ABAB、+1+2…） |
| F | Reasoning 规律推理 | 规律不完全显性，要推出隐藏关系：为什么是它 |
| G | Prediction 预测 | 用规律判断下一步 |
| H | Integrated Judgment 综合判断 | 多属性/多规律同时存在，过滤干扰后综合 |

每个游戏原则上能映射到链上的一个或多个环节。metadata 里用 `cognitiveChain`（`primary` / `secondary`）登记。

## 3. Pattern 维度（规律发生在哪里）

数字 · 数量 · 颜色 · 图形 · 大小 · 空间 · 顺序 · 时间 · 动作 · 视觉差异 · 多属性。
这是内部标签，不直接展示给孩子。一个游戏 ≠ 一个思维能力。

三层结构：**认知链**（在做什么思维动作）→ **维度**（规律在哪里）→ **游戏形式**（前台的 11 个入口，以及未来吸收的新玩法）。

## 4. 11 个入口

保持现状，**不删、不加一级入口**。分类并不处于同一层级（颜色是信息属性，空间是关系类型，逻辑推理是认知过程，综合是复杂度，
找不同是任务形式），前台不需要为此重构，严格性放在后台。

## 5. 增加新游戏的三个问题

1. 它主要训练哪个认知动作？
2. 现有维度能否描述它？
3. 它带来新的思维机制，还是只是新的表现形式？

能容纳就作为新 Template/Game 加入现有分类；只有出现明显的新认知维度才修改一级架构。

### 现状与设计之间的差距（驱动后续工作）

1. **体验单一**：11 个入口几乎都是「看序列 → 从 3–4 个选项里选一个」，没有试错、没有后果演示（综合规律的答对后揭示除外）。
2. **认知链只覆盖了「模式提取 → 补全」**：识别、预测、解释几乎没有；链上 A–D 只有找不同侦探专门练。
3. ~~空间关系是唯一没有生成器、缺 K1/K2 的入口~~：已改为生成式位置规律（K1–G2），「找路线」移出，归策略大师。
4. **逻辑推理**与数学逻辑的「排队与比较」重叠，且仍是文字前提加选择题。
5. **数字规律**与数学数感/规律重叠最多，且是纯符号，离游戏感最远。

## 7. 难度成长

难度来自认知复杂度，不是数字变大、对象变多。独立的轴：

- 单属性 → 多属性
- 显性规律 → 隐性规律（ABAB → AABAAB → 嵌套）
- 静态 → 动态
- 局部 → 整体
- 单规则 → 多规则
- 识别 → 补全 → 预测 → 解释（解释用选择理由的结构化方式，不依赖 AI 判断自由文本）
- 低干扰 → 高干扰

## 8. 游戏设计原则

游戏优先；短周期；低文字依赖；规则简单、思考可以复杂；参数化（一个 Template 生成大量 Variant）；
允许试错（错误是信息）；即时反馈；不追求题量；少用积分排名；从优秀游戏提取机制而不是复制外观。

**体验约定（沿用策略大师，不改 shell）**
- 选错不判红叉：演示「按你选的会怎样」，再让孩子改；
- 完成即通过（1 分）；首次且无提示完成为最优，多一个 ⭐；
- 重试、提示、各档（best/better/good/valid）次数写进 `getReportContext` 的 `process`。

## 9. 统计与 RootGene

不只统计「数字规律做了多少题」，而是逐步积累观察、比较、变化检测、空间、序列、模式识别、推理、预测、多属性等底层能力的行为数据。
`cognitiveChain` 标签是这条路径的第一步；RootGene 仍沿用现有基因，不新增。

## 10. 路线

1. 本文档、入口页文案、各模块 metadata 的 `cognitiveChain` 标签。（已完成）
2. 以颜色规律为样板，把玩法从「选一个」升级为「试再判」：加入预测与识别，补全链条；选错演示后果。
